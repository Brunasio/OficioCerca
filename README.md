# Oficio Nearby

Quiero crear una plataforma web llamada provisionalmente OficioCerca, similar a Uber, pero dedicada a conectar clientes con profesionales de oficios a domicilio.

La primera etapa funcionará en Puerto Tirol y Resistencia, Chaco, Argentina.

La plataforma debe tener dos modalidades:

Buscar un profesional por oficio, localidad, calificación y disponibilidad.

Publicar una necesidad para que los técnicos registrados puedan verla, postularse y ofrecer sus condiciones.

Incluir categorías de electricidad, plomería, gas, refrigeración, albañilería, pintura, carpintería y reparación de electrodomésticos.

Crear una interfaz moderna, profesional, intuitiva y adaptable a celulares y computadoras, en español y con precios expresados en pesos argentinos.

Diseñar las siguientes pantallas: inicio, categorías, listado de profesionales, perfil del técnico, publicación de solicitudes, detalle del trabajo, panel del cliente, panel del técnico y panel administrativo.

En esta primera versión, usar datos ficticios para demostrar los recorridos completos. No procesar pagos reales ni mostrar reseñas ficticias como si fueran auténticas.

Organizar el proyecto para poder incorporar posteriormente una base de datos, autenticación, notificaciones y pagos online.

Primero generá el prototipo navegable y explicá cómo probarlo antes de agregar funciones más complejas.
